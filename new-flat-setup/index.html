The floor-care decision

Keep the Dyson. Add one spray mop.

Settled

Dyson V12 + refillable microfibre spray mop

  • Dyson V12: routine dry debris, rugs, edges, skirting, furniture and dust.
  • Spray mop: controlled, low-moisture cleaning of the engineered wood; washable pad rather than disposable Swiffer sheets.
  • Tile rooms: use the same mop with the appropriate hard-surface bottle/pad, or a separate labelled pad.

Skip the wet/dry vacuum

It duplicates equipment you already own, adds a dirty-water tank and roller to maintain, and is less useful for rugs, furniture and detailed dry cleaning. Also skip a bucket and second vacuum.

Important: the inventory calls the main flooring “engineered wood” but does not identify whether it is sealed/lacquered or oiled. Confirm the finish before choosing the cleaning formula.

Start here

Three baskets, then stop.

This keeps setup from becoming a full-day project. Each basket is a separate 30–45 minute block.

Floor-care pair

Your Dyson is covered. Order one refillable wood-floor spray mop, the correct solution and one spare washable pad.

3

Main bed + bathroom

Bedroom 1 is king size. Buy only the main-bed protector, sheets and duvet set, plus towels and a bath mat. Defer the guest bed.

Recovery guardrails

Low-friction, bounded setup

One block per day30–45 minutes is enough. A usable flat is the goal, not a finished flat.
One daylight safety checkTest existing alarms, doors and accessible windows once; repeat only for genuinely new objective evidence.
No security expansionNo indoor cameras, smart lock, additional locks, security bars or alarm hub.
No speculative equipmentNo dehumidifier, window vac or acoustic hardware unless an actual, sustained problem appears.
